= 理解向量

image::vector_2d_coordinates.png[width=150, role = "right"]

向量具有维度和方向。
例如，下图在笛卡尔坐标系中描绘了一个二维向量 stem:[\vec{a}]，用箭头表示。

向量 stem:[\vec{a}] 的头部位于点 stem:[(a_1, a_2)]。
*x* 坐标值为 stem:[a_1]，*y* 坐标值为 stem:[a_2]。这些坐标也被称为向量的分量。

[[vectordbs-similarity]]
== 相似性

可以使用多种数学公式来确定两个向量是否相似。
其中最直观且易于理解的是余弦相似度。
考虑以下显示三组图表的图像：

image::vector_similarity.png[align="center",width=600]

当向量 stem:[\vec{A}] 和 stem:[\vec{B}] 指向彼此接近时，它们被认为是相似的，如第一个图表所示。
当向量彼此垂直时，它们被认为是不相关的；当它们指向相反方向时，它们被认为是相反的。

它们之间的角度 stem:[\theta] 是衡量它们相似性的好方法。
如何计算角度 stem:[\theta]？

image:pythagorean-triangle.png[align="center",width=100, role="left", trim="10 10 10 100"]

我们都熟悉 https://en.wikipedia.org/wiki/Pythagorean_theorem#History[毕达哥拉斯定理]。

当 *a* 和 *b* 之间的角度不是 90 度时怎么办？

引入 https://en.wikipedia.org/wiki/Law_of_cosines[余弦定律]。

.余弦定律
****
stem:[a^2 + b^2 - 2ab\cos\theta = c^2]
****

下图显示了这种方法的向量图：
image:lawofcosines.png[align="center",width=200]

这个向量的大小根据其分量定义如下：

.大小
****
stem:[\vec{A} * \vec{A} = ||\vec{A}||^2 = A_1^2 + A_2^2 ]
****

两个向量 stem:[\vec{A}] 和 stem:[\vec{B}] 之间的点积根据其分量定义如下：

.点积
****
stem:[\vec{A} * \vec{B} = A_1B_1 + A_2B_2]
****

用向量大小和点积重写余弦定律得到以下结果：

.向量形式的余弦定律
****
stem:[||\vec{A}||^2 + ||\vec{B}||^2 - 2||\vec{A}||||\vec{B}||\cos\theta = ||\vec{C}||^2]
****

将 stem:[||\vec{C}||^2] 替换为 stem:[||\vec{B} - \vec{A}||^2] 得到以下结果：

.仅用 stem:[\vec{A}] 和 stem:[\vec{B}] 表示的向量形式余弦定律
****
stem:[||\vec{A}||^2 + ||\vec{B}||^2 - 2||\vec{A}||||\vec{B}||\cos\theta = ||\vec{B} - \vec{A}||^2]
****

https://towardsdatascience.com/cosine-similarity-how-does-it-measure-the-similarity-maths-behind-and-usage-in-python-50ad30aad7db[展开这个式子] 就得到了 https://en.wikipedia.org/wiki/Cosine_similarity[余弦相似度] 的公式。

.余弦相似度
****
stem:[similarity(vec{A},vec{B}) = \cos(\theta) = \frac{\vec{A}\cdot\vec{B}}{||\vec{A}\||\cdot||\vec{B}||]
****

这个公式适用于高于 2 或 3 维的情况，虽然难以可视化。但是，https://projector.tensorflow.org/[可以在一定程度上进行可视化]。
在 AI/ML 应用中，向量通常有数百甚至数千个维度。

使用向量分量在更高维度中的相似度函数如下所示。
它通过使用 https://en.wikipedia.org/wiki/Summation[求和数学语法] 将前面给出的二维大小和点积定义扩展到 *N* 维。

.使用向量分量的余弦相似度
****
stem:[similarity(vec{A},vec{B}) = \cos(\theta) = \frac{ \sum_{i=1}^{n} {A_i  B_i} }{ \sqrt{\sum_{i=1}^{n}{A_i^2} \cdot \sum_{i=1}^{n}{B_i^2}}]
****

这是向量存储简单实现中使用的关键公式，可以在 `SimpleVectorStore` 实现中找到。
