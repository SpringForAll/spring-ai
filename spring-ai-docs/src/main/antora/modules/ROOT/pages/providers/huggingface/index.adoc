= Hugging Face

获取众多机器学习和人工智能模型最简单的方式之一，就是使用 https://en.wikipedia.org/wiki/Hugging_Face[Hugging Face 的] https://huggingface.co/inference-endpoints[推理端点]。

Hugging Face Hub 是一个平台，为创建和分享数以万计的开源 ML/AI 模型、数据集和演示应用程序提供了协作环境。

推理端点允许你以按需付费的方式，在专用基础设施上部署 AI 模型。
你可以使用 Amazon Web Services、Microsoft Azure 和 Google Cloud Platform 提供的基础设施。
Hugging Face 也允许你在自己的机器上运行模型，但通常本地没有足够的 CPU/GPU 资源来运行更大、更专注于 AI 的模型。

它提供了对 Meta 最近（2023 年 8 月）发布的 Llama 2 和 CodeLlama 2 模型的访问，并提供了 https://huggingface.co/spaces/HuggingFaceH4/open_llm_leaderboard[开放 LLM 排行榜]，你可以在这里快速发现高质量模型。

虽然 Hugging Face 提供了免费托管层，非常适合快速评估某个 ML/AI 模型是否符合你的需求，但通过 https://huggingface.co/docs/text-generation-inference/main/en/index[文本生成接口 API]，你无法在免费层访问许多模型。如果你最终还是要用于生产环境，建议付费几美分来体验可靠的解决方案。价格低至每 CPU 核心每小时 $0.06，每 GPU 每小时 $0.6。
